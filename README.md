# AAS mail

![AAS mail](docs/media/aas-mail-github-preview.png)

Локальный клиент почты и календаря для двух рабочих ящиков поверх Exchange ActiveSync.
Здесь только релизы; исходный код — в приватном репозитории.

## Установка (macOS)

```bash
curl -fsSL https://raw.githubusercontent.com/olesyaba/aas-mail/main/install.sh | bash
```

Или вручную: скачать архив со страницы [Releases](https://github.com/olesyaba/aas-mail/releases/latest).
Windows и Android — там же. Дальше приложение обновляется само (Настройки → Обновления).
