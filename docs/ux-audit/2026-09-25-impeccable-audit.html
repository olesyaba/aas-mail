Список писем и папки недоступны с клавиатуры и скринридера

Строка письма и папка отрисованы как div с обработчиком клика, без role, tabindex и aria-selected. Замер: 14 нажатий Tab подряд проходят только по звёздочкам папок, ни одна папка и ни одно письмо фокус не получают. Горячие клавиши j/k и стрелки есть, но скринридер не озвучит, какое письмо выбрано и прочитано ли оно.

РекомендацияСписок: role="listbox" с roving tabindex, строки role="option", aria-selected, в aria-label отправитель, тема, время и «не прочитано». Папки: button внутри nav, текущая с aria-current="page". Звёздочки убрать из порядка Tab (tabindex="-1", закрепление через контекстное меню или клавишу).

P0#ov #modal

Модалки не удерживают фокус

Compose, настройки и карточка встречи открываются в div#modal без role="dialog" и aria-modal. Замер: после открытия «Нового письма» фокус встаёт в «Кому», но через 12 нажатий Tab уходит на кнопку «Создать» под затемнением. Пользователь с клавиатуры печатает не туда. Escape закрывает модалку, это работает.

РекомендацияПеревести на нативный <dialog> с showModal(): браузер сам даёт фокус-ловушку, inert для фона, Escape и возврат фокуса на кнопку-источник. Перетаскивание окна за заголовок сохраняется. Заголовок модалки связать через aria-labelledby.

Системные проблемы

Интерактив на div'ах

Строки, папки, карточки писем в цепочке, события календаря собираются строками innerHTML (36 мест) из div с onclick. Отсюда сразу три P0/P1: нет фокуса, нет ролей, мелкие зоны клика. Лечится один раз на уровне шаблонов, а не точечно.

Раскладка без точек перестройки

Ширины колонок и панели инструментов заданы в пикселях, а сужение решается overflow: hidden и скрытым скроллом. Нужна одна стратегия: container queries для панелей и 2 точки для каркаса.

Что сделано хорошо

  • Токенная система: 8 тем, акцент по аккаунту, dark-варианты
  • Контраст основного текста 13-17:1 во всех темах
  • Тело письма в sandbox-iframe без скриптов, CSP default-src 'none', картинки по запросу
  • Весь HTML из данных проходит через esc()
  • Горячие клавиши j/k, стрелки, Delete, Escape для модалок
  • prefers-reduced-motion обнуляет длительности
  • Все 275 кнопок имеют доступное имя (текст, aria-label или title)
  • Переходы только по transform, background и box-shadow, 180 мс
