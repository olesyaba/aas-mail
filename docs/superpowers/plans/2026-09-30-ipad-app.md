# AAS mail for iPad Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An iPad app that runs the shared `webapp.py` on embedded Python 3.12 and shows it in a WKWebView, signed with the free personal team.

**Architecture:** `ios/build_ios.sh` downloads BeeWare `Python.xcframework` 3.12-b10 (cached in `ios/vendor/`), stages `app/` (webapp.py, bridge.py, vendored client, ios_entry.py, ios_keychain.py, web/) and `app_packages/` (pure-Python requests stack), generates the Xcode project with `xcodegen` from `ios/project.yml` and builds with `xcodebuild` (DEVELOPER_DIR=Xcode.app). A C host (`PyHost.c`) initialises Python the way BeeWare's testbed does and runs `ios_entry.run()` on a background thread; Swift waits for `/api/about` with our token and loads the page.

**Tech Stack:** Swift 6 / SwiftUI / WebKit, C (Python C API), Python 3.12, xcodegen 2.46, Xcode 27 (iPadOS SDK 27), simctl/devicectl.

**Spec:** `docs/superpowers/specs/2026-09-30-ipad-app-design.md`

## Global Constraints

- Bundle id `ru.olesyaba.aasmail`; display name «AAS mail»; iPadOS 17.0+; iPad only (TARGETED_DEVICE_FAMILY 2); all orientations; multitasking allowed.
- Python 3.12 from `https://github.com/beeware/Python-Apple-support/releases/download/3.12-b10/Python-3.12-iOS-support.b10.tar.gz`.
- Server on `127.0.0.1:8780`, page key via `EAS_MAIL_PAGE_KEY`, token file `<data>/runtime_token` (same contract as Android `PyServer.kt`).
- Data in Application Support/eas-bridge; cache in Caches; Keychain service/account names identical to the Mac (`eas-bridge`, account id).
- No `subprocess` on iOS paths; no network during build except the one xcframework download and `pip download` of pure wheels.
- Signing: free personal team, automatic signing, `-allowProvisioningUpdates`; never commit team id or profiles.

## Review Focus

1. First launch with no config → the setup wizard (credentials) must show, not an error screen.
2. Password saved in Settings survives an app relaunch (Keychain round-trip on device, not just macOS).
3. «Подключиться» with a `ktalk`/`https` link opens outside the app; a letter link never navigates the app's own WebView away from 127.0.0.1.
4. Attachment download ends in the share sheet, not a blank WebView page.
5. App backgrounded for minutes then resumed → page still talks to the (possibly restarted) server; if the thread died, the error screen offers the log.

### Task 3: Swift shell + C host

**Files:** Create `ios/AASMail/AASMailApp.swift`, `PyServer.swift`, `WebView.swift`, `PyHost.h`, `PyHost.c`.

- `PyHost.c`: `int aas_py_run(const char *home, const char *app, const char *packages, const char *data, const char *cache, const char *web, const char *key)` — isolated PyPreConfig/PyConfig (utf8_mode, home=`<bundle>/python`, write_bytecode=0), `Py_InitializeFromConfig`, `site.addsitedir(app_packages)`, `sys.path.insert(0, app)`, `import ios_entry; ios_entry.run(data, cache, web, key)`; on exception `PyErr_Print` to stderr → returns 1.
- `PyServer.swift`: random 24-byte page key; data = Application Support/eas-bridge, cache = Caches; `Thread { aas_py_run(...) }` (8 MB stack); `waitUntilUp()` polls `POST /api/about` with header `X-Tok` from `<data>/runtime_token` every 200 ms, 30 s timeout.
- `WebView.swift` (UIViewRepresentable): loads `http://127.0.0.1:8780/?k=<page key>` (same query contract as Android — check `webapp` page-key handling and mirror `MainActivity.kt`); `decidePolicyFor navigationAction`: host 127.0.0.1 → allow; everything else → `UIApplication.shared.open` and cancel; `navigationResponse` not showable / `download` → `WKDownload` to Caches → `UIActivityViewController` from the key window; `createWebViewWith` (target=_blank) → open externally.
- `AASMailApp.swift`: state machine starting → ready(WebView) | failed(message, share-log button); on `scenePhase == .active` after background, re-check `/api/about`, show failed state if dead.
